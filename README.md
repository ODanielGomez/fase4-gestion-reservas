# Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto desarrollado para la Fase 4 - Prácticas simuladas del curso Programación.

## Objetivo

Desarrollar una aplicación en Python orientada a objetos para gestionar clientes, servicios y reservas de la empresa Software FJ. El sistema aplicará validaciones, manejo de excepciones y registro de eventos y errores.
